A deterministic algorithm counts the satisfying assignments of a 3-CNF on n variables in time O(2^{δn}) for every δ > 0, refuting the Exponential Time Hypothesis; the appendices sharpen this to the Main Theorem's 2^{O(min{k²n log log n/√log n, km/√log m})}. The key step rewrites pairs of equality tests with the eight-square identity so that each level of a recursion on cliques multiplies the exponent by about 11/12.
